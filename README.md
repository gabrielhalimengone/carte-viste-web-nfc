# carte-viste-web-nfc

Carte de visite numérique responsive de Gabriel Endam’Engone.

- `index.html` contient la page, les styles et les interactions.
- `img/gabriel-polo-nuit.png` est la photo rectangulaire utilisée par la carte.
- Les coordonnées et les liens modifiables sont regroupés dans l’objet `PROFILE` en haut du script.
